Repositorio  Model Avaliação de Desempenho


Trabalho de Model Avaliação de Desempenho 


Descrição
Este repositório contém o desenvolvimento de um projeto acadêmico para a disciplina de Avaliação de Desempenho, com o objetivo de identificar os principais fatores que afetam o tempo de resposta em sistemas computacionais. A análise foi realizada utilizando regressão linear múltipla, abordando desde o pré-processamento dos dados até a interpretação dos resultados.

Etapas do Projeto
✔ Pré-processamento dos Dados

Tratamento de valores ausentes (imputação por mediana e moda).

Codificação de variáveis categóricas (One-Hot Encoding).

Verificação e correção de multicolinearidade (VIF).

✔ Análise Exploratória

Estatísticas descritivas (média, desvio padrão, correlações).

Diagnóstico de heterocedasticidade (Teste de White).

Avaliação da normalidade dos resíduos (QQ-Plot, Jarque-Bera).

✔ Modelagem Estatística

Construção de um modelo de regressão linear com todas as variáveis.

Comparação entre modelos completo e reduzido (remoção de variáveis com alta multicolinearidade).

Análise de significância estatística (p-valor) e impacto das variáveis.

✔ Resultados e Recomendações

Identificação das variáveis mais relevantes (CPU e RAM).

Sugestões para otimização de hardware e software.

Propostas para melhorar o modelo (transformação logarítmica, erros robustos).

Objetivo
O projeto visa responder:
🔹 Quais componentes de hardware têm maior impacto no tempo de resposta?
🔹 Como otimizar o sistema para melhor desempenho?
🔹 Quais limitações do modelo podem ser corrigidas em análises futuras?

Tecnologias Utilizadas
Python (Análise de Dados e Modelagem Estatística)

Pandas (Manipulação de Dados)

Statsmodels (Regressão Linear, Testes Estatísticos)

Matplotlib/Seaborn (Visualização de Dados)
